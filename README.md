# Skuyland Seblak

Website profil dan promosi CV Skuyland Kuliner Nusantara, usaha kuliner seblak di Cirebon.

## Fitur
- Desain responsif untuk desktop dan mobile
- Bagian profil usaha, menu, dan kontak
- Filter menu dan tombol WhatsApp
- Konfigurasi kontak melalui `config.js`

## Menjalankan
Buka `index.html` di browser atau jalankan server statis dari folder proyek.

## Konfigurasi
Sesuaikan nomor WhatsApp dan informasi usaha yang belum diisi pada `config.js` sebelum dipublikasikan.
