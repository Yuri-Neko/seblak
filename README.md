# Skuyland Seblak

Website profil dan promosi CV Skuyland Kuliner Nusantara. Skuyland Seblak mulai dibangun pada 26 Februari 2026. Website dibuat dengan HTML, CSS, dan JavaScript tanpa framework.

## Fitur
- Desain responsif untuk desktop dan ponsel
- Profil usaha dan portofolio awal
- Menu seblak dengan pilihan level pedas 0–5
- Kalkulator pesanan: pilihan menu, topping, jumlah porsi, dan estimasi total
- Ringkasan pesanan yang dapat dikirim ke WhatsApp
- Filter menu dan navigasi mobile

## Menjalankan
Buka `index.html` atau jalankan server statis dari direktori proyek.

## Konfigurasi sebelum publikasi
Edit `config.js` dan isi `whatsappNumber` dengan nomor WhatsApp resmi format internasional tanpa tanda plus. Nomor kosong sengaja tidak diganti dengan nomor rekaan; checkout meminta nomor diatur sebelum membuka WhatsApp.

Alamat resmi, jam buka, harga final, foto produk asli, legalitas, sejarah, struktur tim, dan pencapaian CV perlu diverifikasi. Bagian portofolio saat ini adalah profil awal dan tidak mengklaim klien, cabang, sertifikasi, atau pencapaian yang belum terverifikasi.

## Estimasi harga awal (bukan harga resmi)
- Seblak Original: Rp10.000
- Seblak Bakso / Sosis: Rp12.000
- Seblak Ceker: Rp15.000
- Seblak Komplit: Rp18.000
- Topping: sekitar Rp2.000–Rp3.000; telur Rp2.500
- Level pedas: 0–5, tanpa biaya tambahan pada rancangan awal

Estimasi ini diadaptasi dari kisaran menu seblak yang terdaftar online di Cirebon. Harga resmi perlu disesuaikan dengan biaya bahan, ukuran porsi, biaya operasional, dan margin usaha.
